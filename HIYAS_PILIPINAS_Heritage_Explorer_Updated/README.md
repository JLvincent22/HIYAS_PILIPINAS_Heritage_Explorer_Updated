# HIYAS PILIPINAS – Heritage Explorer

Mobile-first heritage map website. Open `index.html` locally or deploy the folder to Vercel.

## Google Maps
Each region uses an editable `mapEmbed` URL where supplied; otherwise the site builds an address-based Google Maps embed. Replace `mapEmbed` with a Google Maps Embed URL from Google Maps > Share > Embed a map if you want to use your own exact embed code.
